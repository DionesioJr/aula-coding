# Manipulando o DOM

Primeira aula de DOM da disciplina de Coding, pensada para quem está
começando: um contador de cliques em HTML e JavaScript puros, sem
bibliotecas e sem npm. Só o essencial:

1. o que é o DOM;
2. achar um elemento da página com `getElementById` (e o `null` quando o id não existe);
3. trocar o texto dele com `textContent`;
4. reagir a um clique com `addEventListener`.

A aula seguinte, [`../manipulando-dom-lista`](../manipulando-dom-lista),
continua daqui: criar elementos, ler o campo de texto e remover itens.

## Executar

Abra [`index.html`](index.html) no navegador e use o Console (F12).
O código fica em [`script.js`](script.js).

## Apresentação da aula

Abra [`aula/index.html`](aula/index.html) no navegador.
