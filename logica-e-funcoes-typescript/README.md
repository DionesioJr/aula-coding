# Lógica e funções em TypeScript

Oito atividades curtas de lógica básica, cada uma implementada como uma
função TypeScript em [`src/atividades.ts`](src/atividades.ts) e testada com
`console.log` em [`src/testes.ts`](src/testes.ts): par ou ímpar, maior de
dois e de três números, fatorial, número primo, classificação de nota,
inverter texto e contar vogais.

Diferente das outras aulas da plataforma, esta não é um app React Native:
é TypeScript puro, sem interface, focada em `if`/`else`, laços e funções
com parâmetros e retorno tipados.

## Instalar

```bash
npm install
```

## Executar

```bash
npm start
```

Isso roda `src/testes.ts` com `ts-node` e imprime o resultado de cada
função no terminal.

## Apresentação da aula

Abra [`aula/index.html`](aula/index.html) no navegador para a versão
interativa: cada atividade aparece primeiro como desafio (a turma tenta
sozinha) e depois como a função sendo digitada, igual às outras aulas da
plataforma.
